# Chrome Web Store Listing - TabGuard

## Name (28 chars)
TabGuard - Trust-first Tab Manager

## Short description (132 chars max)
Save, restore, and back up tabs with verified integrity. No silent failures. No lock-in. Export any time.

## Detailed description

Other tab managers say "session saved" but restore shows only 1 tab. They say "backup created" but the file is empty. One Chrome update wipes everything.

TabGuard fixes this one thing: TRUST.

We read 30 recent reviews of the top 3 tab managers (Session Buddy, Tabs Outliner, FreshStart - 1.16M combined users). 41 percent of complaints were about data integrity.

FEATURES
- Verified saves: SHA-256 checksum + post-save verification badge
- Restore preview: see how many tabs and the first URLs before opening
- Export any time to JSON
- Auto-backup every 30 minutes while Chrome is open
- Delete with confirmation
- Local only: no server, no analytics, no telemetry
- Zero network requests
- Minimal permissions: tabs, storage, unlimitedStorage, alarms (no site access)

PRICING
Free. All features included. No account, no payment, no lock-in.
A Pro tier with extra features may be offered in the future, and existing users will be notified.

## Single purpose (required by CWS)
TabGuard saves, restores, and backs up the user's browser tab sessions with integrity verification. It does not modify web pages, inject content scripts, or act as a general productivity suite.

## Permission justification (required by CWS)

- tabs: Required to read the URL and title of the tabs the user explicitly asks to save in a session, and to restore them.
- storage: Required to persist the user's saved sessions and preferences.
- unlimitedStorage: Required to store an unbounded number of saved sessions in IndexedDB without quota errors.
- alarms: Required to schedule the 30-minute auto-backup job.
