## Detailed description

Other tab managers say session saved but restore shows only 1 tab. They say backup created but the file is empty. One Chrome update wipes everything.

TabGuard fixes this one thing: TRUST.

We read 30 recent reviews of the top 3 tab managers (Session Buddy, Tabs Outliner, FreshStart - 1.16M users). 41 percent of complaints were about data integrity.

FEATURES
- Verified saves: SHA-256 checksum + post-save verify
- Restore preview: tabs, windows, RAM estimate before opening
- Export any time to JSON
- Auto-backup every 30 min
- Delete with confirmation
- Local only: no server, no telemetry
- Minimal permissions: tabs, storage, alarms (zero host perms)
